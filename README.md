# PA Portfolio (Y2K Edition)

ระบบรายงานผลการปฏิบัติตามข้อตกลงในการพัฒนางาน (PA) ในธีม Y2K / Windows 98 — หน้าเว็บเดียว (single-page), ไม่มี backend, แก้ไขง่าย

🔗 **เว็บที่ใช้งานจริง:** https://firstkaokao-ux.github.io/pa-portfolio/

## เนื้อหาในหน้าเว็บ

หน้าเว็บแบ่งเป็น 5 แท็บ (จำลองหน้าต่าง Windows 98):

| แท็บ | เนื้อหา |
|---|---|
| หน้าแรก | ข้อมูลผู้รับการประเมิน (ชื่อ, ตำแหน่ง, โรงเรียน) |
| ข้อมูลทั่วไป | สรุปภาระงาน, ชั่วโมงสอน, งานพิเศษ/โฮมรูม |
| PA ส่วนที่ 1 | ข้อตกลงในการพัฒนางาน / ประเด็นท้าทาย |
| PA ส่วนที่ 2 | การจัดการเรียนรู้, การดูแลผู้เรียน, PLC |
| ผลลัพธ์ผู้เรียน | สถิติผลการเรียน + ผลงานนักเรียน |

## วิธีแก้ไขเนื้อหา

ทั้งเว็บอยู่ในไฟล์เดียวคือ [`index.html`](index.html) — เปิดด้วยโปรแกรมแก้ไขข้อความ (Notepad, VS Code) แล้วแก้ได้เลย ไม่ต้องมีเครื่องมือ build ใดๆ

จุดที่ต้องกรอกข้อมูลจริงคือข้อความในวงเล็บเหลี่ยม เช่น `[ระบุชื่อ-สกุล]`, `[ระบุโรงเรียน]`, `[แทรกรูปโปรไฟล์ 3x4]` — ค้นหาคำว่า `[ระบุ` หรือ `[แทรก` ในไฟล์เพื่อหาจุดที่ยังไม่ได้กรอกทั้งหมด

### ใส่รูป/วิดีโอ

- **รูป:** วางไฟล์รูปไว้โฟลเดอร์เดียวกับ `index.html` แล้วแทนที่ placeholder ด้วย `<img src="ชื่อไฟล์.jpg">`
- **วิดีโอ:** แนะนำอัปโหลดขึ้น YouTube แล้วฝัง embed code แทนไฟล์วิดีโอโดยตรง (ไฟล์วิดีโอจะทำให้เว็บโหลดช้าและพื้นที่ repo เต็มเร็ว)

## ดูตัวอย่างก่อน deploy (รันในเครื่อง)

ไม่มี build step ใดๆ เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือถ้าต้องการเสิร์ฟผ่าน local server:

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## Deploy

เว็บนี้ deploy ผ่าน **GitHub Pages** จาก branch `main` (root) อยู่แล้ว — แก้ไฟล์ `index.html`, commit, push ขึ้น `main` เว็บจะอัปเดตอัตโนมัติภายใน 1-2 นาที ไม่ต้องตั้งค่าอะไรเพิ่ม

```bash
git add index.html
git commit -m "อัปเดตข้อมูล PA"
git push
```
